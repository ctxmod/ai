# AI

AI development doctrine for ctxmod (`github.com/ctxmod/ai/context`). Requires `github.com/ctxmod/engineering/context`.

Profiles:

- `agentic_development` (default): packages `evaluation`, `orchestration`, `telemetry`.
- `rag`: retrieval-augmented generation practice (package `practice`); extends `agentic_development`.

Select a profile by its qualified name, e.g. `github.com/ctxmod/ai/context/profiles/rag`.
